# CLINIC GO-LIVE INPUT & ONBOARDING TEMPLATE
## GNU HEALTH HMIS 5.0 / TRYTON 7.0 (OUTPATIENT CLINIC)

**Classification**: Official Stakeholder Data Intake Template  
**Target Organization**: Primary Outpatient & Ambulatory Healthcare Facility  
**Instructions for Clinic Stakeholders**:  
Please complete each required section below with official, verified organizational records. **Do not submit synthetic or placeholder information.** Fields marked `REQUIRED BEFORE GO-LIVE` must be submitted and validated before the clinical system can be officially authorized for patient registration and care delivery.

---

## Field Classification Key
- **[REQUIRED BEFORE GO-LIVE]**: Mandatory for basic legal operation, invoicing, and patient documentation.
- **[REQUIRED FOR SPECIFIC WORKFLOW]**: Mandatory only if that department/workflow (e.g. Lab, Radiology, Insurance) is operational on Day 1.
- **[OPTIONAL]**: Secondary enhancement; not gating basic outpatient consultations.
- **[NOT CURRENTLY REQUIRED]**: Deferred to Phase 2 (e.g. Inpatient, Intensive Care, Blood Bank).
