# GNU HEALTH HMIS 5.0 — FRONTEND WORKFLOW MATRIX

**Document ID:** GNU-HEALTH-FE-MATRIX-2026-09-22  
**Target Audience:** Frontend Developers, QA Automation Engineers, System Integrators  
**Authoritative Backend:** GNU Health HMIS 5.0 / Tryton 7.0 / PostgreSQL 15.19  

This matrix defines the **authoritative mapping** between every clinic frontend user action, the corresponding Tryton JSON-RPC method, the authoritative backend model, authorized roles, state transitions, expected responses, and error cases.
